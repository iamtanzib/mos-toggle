Mos Toggle

Auto-turns off Mos smooth scrolling while After Effects or Premiere Pro is in front, and turns it back on in every other app. Runs hidden, starts at login.

Download MosToggle.zip

Install

  1. Install Mos first.
  2. Unzip MosToggle.zip.
  3. Right-click install.command → Open → Open.
  4. Done. It runs in the background and starts on every login.

What's in the zip

  • install.command: installs and starts the background service.
  • Mos Toggle Start.app: starts it again if you stopped it. No window.
  • uninstall.command: stops and removes everything.
  • mos-toggle.sh: the script itself.

How it works

A macOS LaunchAgent runs this loop. Every second it checks the front app. If it is After Effects or Premiere Pro, Mos is quit. Otherwise Mos is relaunched.

while true; do
  app=$(lsappinfo info -only name "$(lsappinfo front)")
  if [[ $app == *"After Effects"* || $app == *"Premiere Pro"* ]]; then
    pgrep -xq Mos && killall Mos
  else
    pgrep -xq Mos || open -gb com.caldis.Mos
  fi
  sleep 1
done

Uninstall

Run uninstall.command, or:

launchctl bootout gui/$(id -u)/com.user.mostoggle
rm ~/Library/LaunchAgents/com.user.mostoggle.plist

macOS may warn that the files are from an unidentified developer. Use right-click → Open. Mos may take up to 1 second to switch off or on.
